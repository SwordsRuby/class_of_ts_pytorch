## Проект: Локальный классификатор текстовых заявок (Task 2)

### 1. Общее описание
Разрабатывается легковесный классификатор на Python для автоматической маршрутизации входящих текстовых заявок (ТЗ) по 5 категориям:
- **Веб-разработка**
- **Мобильное приложение**
- **Дизайн**
- **Аналитика**
- **Маркетинг**

Ключевые требования: использование PyTorch или Scikit-learn, генерация собственного датасета (10 примеров на категорию), выполнение в локальной среде.

### 2. Архитектура решения
Проект строится по модульному принципу и включает следующие этапы:

1. **Генерация данных**
   - Скрипт создаёт синтетический датасет из 50 текстов (10 на категорию).
   - Тексты содержат ключевые слова и типовые формулировки для каждой категории.

2. **Предобработка текста**
   - Приведение к нижнему регистру.
   - Удаление стоп-слов (опционально, для эксперимента).
   - Токенизация и векторизация (TF-IDF / Bag-of-Words).

3. **Обучение модели**
   - Два подхода для сравнения:
     - **Классический ML**: LogisticRegression или SVM из Scikit-learn.
     - **Нейросеть**: многослойный перцептрон (MLP) на PyTorch с 1-2 скрытыми слоями.
   - Разделение данных: тренировочная (80%) и тестовая (20%) выборки.

4. **Оценка качества**
   - Метрики: Accuracy, Precision, Recall, F1-score.
   - Матрица ошибок (confusion matrix) для визуализации.

5. **Инференс (предсказание)**
   - Функция `predict(text)`, которая принимает новый текст и возвращает категорию и вероятность.
